Open source · Public beta

Give your coding agent lasting context and a clear workflow.

Contract Graph Dev Kit is a framework for agentic software development. Its skills and tools keep project intent, responsibilities, and dependencies alongside your code, and guide agents through planning, implementation, review, and verification.

Each new session can use that shared context to understand your software, locate the right place for a change, and carry agreed work through to completion.

Get started

Step 1: Install in a terminal

npm install -g contract-graph

Step 2: Choose an option

In the repository’s terminal

cg init

On Windows PowerShell, run cg.cmd init when cg does not start.

Then, in your coding agent

/cg-warmup

Confirm project context before delivery. Full setup guide.

In your coding agent

Use "cg analyse" (or "cg.cmd analyse" on Windows PowerShell) to assess this repository for Contract Graph adoption.

Your repository stays unchanged. Assessment guide.

Requires Node.js 18.17+.
